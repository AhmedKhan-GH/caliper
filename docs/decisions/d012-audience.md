# D12. Audience is collaborators who build from source

| Date | Status |
|---|---|
| 2026-06-10 | Proposed |

## Decision

The current audience is collaborators who build Caliper from source. The contracts are sized so that they also work for end users who install a prebuilt bundle later.

## Reason

This is an assumption about who uses the project. It keeps the effort on the contracts rather than on installers, and it should be revisited when a real end user appears.
