# Roadmap

The roadmap lists every feature of Caliper, what each one depends on and how far it has come. In the graph, each horizontal band holds one pillar of the project. Features that are shipped on `main` sit on the left, and the work that depends on them extends to the right.

Hover over a feature to read its summary, click it to show what it depends on and what it unblocks, and double-click it to open its page. The registry behind this page is the set of YAML files in the repository's [`roadmap/`](https://github.com/AhmedKhan-GH/caliper/tree/main/roadmap) folder.
