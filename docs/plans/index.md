# Plans

Plans describe work that is not built yet. The [roadmap](roadmap.md) is the one place for order and status; each other page here is a technical proposal that the roadmap points to. When a proposal is built, its content moves into the guides, references and explanations, and the proposal page is deleted.

| Page | Proposal |
|---|---|
| [Roadmap](roadmap.md) | The phases of work, smaller work, open questions and the ideas still undecided |
| [Applets outside the core](applets-outside-the-core.md) | Build, store and install applets outside this repository, so the host ships with none and names none |
| [Platform candidates](platform-candidates.md) | Pieces that applets built for themselves and that belong in the host or the SDK |
| [Applet builder](applet-builder.md) | Panels that an agent builds from a declarative spec, through a command layer shared with outside agents |
| [Applet registry](registry.md) | A registry at caliperapp.ai, a Browse tab and install by id and version |
| [Data and the platform](data-and-platform.md) | What data the local tool keeps, and the separate platform that would add run history, shared storage, accounts and hosted sessions |
| [Streaming and embedding](streaming-and-embedding.md) | Using Caliper from other programs: streaming over the network, a viewer in the browser, and the embedding package |
