# Guides

Guides answer one practical question each. They assume you have finished the [tutorials](../tutorials/index.md).

| Page | Question it answers |
|---|---|
| [Debug an applet](debug-an-applet.md) | How do I attach a debugger, read the logs and find out why an applet was refused or quarantined? |
| [Attach to a running script](attach-to-a-running-script.md) | How do I open a live view of a Python script that is already running? |
| [Continuous integration](ci.md) | What runs on each push, what is cached, and what do I do when a run fails? |

The [ML applet cookbook](https://github.com/AhmedKhan-GH/caliper/blob/main/docs/guides/ml-applet-cookbook.md) collects patterns from the applets in this repository. It stays in the repository and is not published on this site, because the applets are not shipped.
