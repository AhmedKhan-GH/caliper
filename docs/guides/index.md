# Guides

Guides answer one practical question each. They assume you have finished the [tutorials](../tutorials/index.md).

| Page | Question it answers |
|---|---|
| [Debug an applet](../applets/applet-debugging.md) | How do I attach a debugger, read the logs and find out why an applet was refused or quarantined? |
| [Embed Caliper in a program](../web/program-embedding.md) | How do I run Caliper applets inside a view of my own program with the `caliper-embed` package? |
| [Attach to a running script](../python/script-attachment.md) | How do I open a live view of a Python script that is already running? |
| [Run a hub](../python/hub-setup.md) | How do I stream several scripts to one address and keep a run viewable after its script ends? |
| [Control a running script](../python/script-control.md) | How do I pause a training loop, change its parameters, run an action and link selections between its views while it trains? |
| [Verify on Windows hardware](verify-on-windows.md) | How do I check a change on the Vulkan and CUDA paths with an NVIDIA GPU? |
| [Continuous integration](ci.md) | What runs on each push, what is cached, and what do I do when a run fails? |

The [ML applet cookbook](https://github.com/AhmedKhan-GH/caliper/blob/main/docs/guides/ml-applet-cookbook.md) collects patterns from the applets in this repository. It stays in the repository and is not published on this site, because the applets are not shipped.
