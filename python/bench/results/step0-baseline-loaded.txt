# Renderer core, step 0: the baseline TAKEN UNDER LOAD (2026-11-15), superseded by step0-baseline.txt

This run's files carry "-step0-loaded" in their names. The quiet rerun replaced it.

NOT A QUIET MEASUREMENT. Repeat every timing below on a quiet machine before step 5's comparison.
The rules for a timing measurement were followed: each benchmark waited for a heavy-job slot with every
other slot free and the 1-minute load average below 8. Five builders shared the machine; it was never
quiet in 40 minutes of waiting (22:30 to 23:11), so the benchmarks then ran with the load stated beside
every row (1-minute load 2.7 to 32.9 over the run). The spread of steps per second between repeats (6 to
48 points of the control) is far above the 2-point threshold, so these numbers record the shape of the
baseline, not a reference for the thresholds. The copy counters do not depend on load.

Machine: an Apple Silicon Mac (M-series Max, 18 cores, 64 GB), macOS 27, on mains power.
Build: Release, preset release-notorch (CALIPER_WITH_TORCH=OFF), Python 3.13, torch 2.15.0 (MPS).
Commits: after = 3717239 (step 0: counters, Metal statistics, points row); before = bae8c25 (its parent
on sprint4-build, for the interleaved 1024 comparison only). Viewer: caliper-viewer --headless --stats
(an offscreen canvas that polls and draws about 50 times a second; no window may open on this machine).
Files: S-table-mps1024-step0-loaded-r1..r3.txt (after) and S-table-mps1024-step0-loaded-before-r1..r3.txt (before),
run interleaved before r1, after r1, before r2, ...; S-table-mps256-step0-loaded.txt, S-table-mps2048-step0-loaded.txt,
S-table-points-mps100000/1000000/4000000-step0-loaded.txt (3 interleaved repeats each);
P-window-mps-1024-step0-loaded.txt and P-attach-mps-1024-step0-loaded.txt (bench_show.py, one run each).
