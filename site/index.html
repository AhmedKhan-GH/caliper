04 · Build

Build from source

CMake 3.25 or later and a C++17 compiler. macOS needs Xcode command line tools and Apple Silicon; Windows needs Visual Studio 2022 and CUDA 12.8.

macOS
Metal, default · MPS tensors on the GPU
Windows
Vulkan, default · CUDA tensors through external memory
Fallback
OpenGL 3.3 core · CPU-staged upload
