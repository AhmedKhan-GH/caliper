Machine learning visualization from VRAM

Caliper validates supported MPS and CUDA tensor inputs, then uses Metal or Vulkan to colormap or blit them into live ImGui textures. Imported geometry is drawn from the same device-resident allocation system.

01 · Frame path

Tensor views stay inside the frame loop

For supported inputs on native backends, Caliper hands tensor storage to the renderer without a host-memory round trip. Colormap and blit work remain on the GPU, and ImGui receives the resulting texture in the same frame.

Curve and scatter coordinates may still use small CPU arrays. The device-resident paths cover accepted dense textures and geometry drawn from imported allocations.

02 · Native backends

Native backends use different memory handoffs

The sequence stays consistent: validate the descriptor, process the data on the active GPU backend, and present the result through ImGui. Storage and synchronization differ by platform.

03 · Processing pipeline

How input becomes a rendered view

A DLPack-aligned descriptor carries the device, type, shape, strides, and optional stream. Caliper validates that descriptor before selecting the active renderer path.

1

Validate the descriptor

Checks device compatibility, data type, dimensions, layout, and byte extent before renderer access. Unsupported inputs are rejected rather than reinterpreted.

2

Process device memory

Accepted 2-D f32 data runs through a LUT colormap; accepted RGBA8 data uses a blit path. Metal and Vulkan perform this work on the GPU.

3

Present and update

The renderer exposes an opaque texture ID to ImGui, updates the same resource for matching shape and type, and releases it on the frame thread.

06 · Build

Build from source

CMake 3.18 or later and a C++17 compiler. macOS needs Xcode command line tools and Apple Silicon; Windows needs Visual Studio 2022 and CUDA 12.8.

Prerequisites → 
# Initialize submodules
$ git submodule update --init --recursive

# Configure (macOS MPS)
$ cmake -B build -DUSE_CUDA=OFF -DUSE_MPS=ON

# Build
$ cmake --build build --config Release -j8

# Run
$ ./build/caliper
