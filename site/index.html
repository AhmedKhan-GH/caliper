        ? torch::Device(torch::kCUDA)
    : (d.kind == CALIPER_DEV_METAL) ? torch::Device(torch::kMPS)
                                    : torch::Device(torch::kCPU);

05 · Build

Build from source

CMake 3.25 or later and a C++17 compiler. macOS needs Xcode command line tools and Apple Silicon; Windows needs Visual Studio 2022 and CUDA 12.8.

macOS
Metal, default · MPS tensors on the GPU
Windows
Vulkan, default · CUDA tensors through external memory
Fallback
OpenGL 3.3 core · CPU-staged upload
Prerequisites → 
# Initialize submodules
$ git submodule update --init --recursive

# Configure and build; the applets download LibTorch
$ cmake --preset release
$ cmake --build --preset release

# Run
$ ./cmake-build-release/caliper
