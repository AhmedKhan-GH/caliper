02 · Caliper Lib

Caliper Lib

The caliper Python package. Version 0.1.0, for Python 3.12 on macOS with Apple Silicon, built from source.

Available
show, points, series, histogram
Send a tensor to a heatmap, a scatter, a curve or a histogram. The call returns at once; the copy runs on the tensor's own GPU stream.
watch(model)
Shows each module's activations, and optionally its gradients, through forward and gradient hooks.
session()
Opens the shared-memory session the Caliper app attaches to with F4, Attach to process.
window(), run(train)
Opens a Caliper window inside the script's own process; run trains on a worker thread so the window stays responsive.
offscreen()
Renders without a window and reads back pixels, values and counters, so tests can check what a view shows.
caliper.live
Lists the running sessions and starts a viewer for one, for tools that attach on their own.

03 · Development

Development

Interfaces
caliper::Applet
The class an applet derives from: the host calls on_init once, on_frame every frame and on_cleanup when the applet closes.
caliper::Device
Reports the GPU the app is running on (Metal, CUDA or the CPU), so the applet trains on the same device.
caliper::Bridge
Turns a GPU tensor into a texture the interface can draw, colormapped on the GPU without a copy to the CPU.
caliper::Geometry
Draws points, lines, meshes and instanced shapes straight from vertex data the applet keeps in GPU memory.
caliper::Jobs
Runs work such as training on a background thread, with progress shown in the app and a cancel the applet checks.
caliper::Metrics
Records each run's scalars and hyperparameters, so loss curves and run comparisons outlast the session.
caliper::Data
Runs SQL over the app's built-in analytical store and returns Arrow tables; datasets can be registered and shared between applets.
caliper::Artifacts
Stores checkpoints and exports by their content, so identical files are kept once and each records where it came from.
caliper::Export
Re-renders a view offscreen at any resolution and saves a pixel-exact PNG, alone or as a sequence, with a JSON record of how it was made.

04 · Build

Build from source

CMake 3.25 or later and a C++17 compiler. macOS needs Xcode command line tools and Apple Silicon; Windows needs Visual Studio 2022 and CUDA 12.8.

macOS
Metal, default · MPS tensors on the GPU
Windows
Vulkan, default · CUDA tensors through external memory
Fallback
OpenGL 3.3 core · CPU-staged upload

Caliper CLI

Create, build, run and capture applets from a terminal, a script or a CI job.

$ caliper new finetune_scope$ caliper build finetune_scope$ caliper run finetune_scope$ caliper capture loss -o loss.png

Caliper API

An HTTP interface to the running app, so code in any language can run applets, send them data and fetch what they show.

# CALIPER is the running app's address$ curl -X POST \    $CALIPER/applets/finetune_scope/run$ curl -X POST $CALIPER/streams/loss \    -d '{"step": 1200, "value": 0.41}'$ curl -o loss.png $CALIPER/views/loss.png

Caliper MCP

Tools that hand your coding agent Caliper's SDK, its documentation and the running app, so it can write a panel for your project, build it and check the result on screen.

$ claude mcp add caliper -- caliper-mcp$ codex mcp add caliper -- caliper-mcp$ claude> Plot the loss of each layer.  new("finetune_scope")  build("finetune_scope")  run("finetune_scope")  capture("loss")

Caliper Bench

Live measurements and telemetry streaming into Caliper, beside the models trained on them, across the physical sciences and engineering.

Example

A robot arm streams its seven joint angles over ROS 2, 500 times a second. Caliper plots them live beside the angles your control policy predicted, so you see the moment the two diverge.

Caliper Cloud

A paid plan that runs Caliper on our dedicated GPU nodes, for models larger than your own hardware can hold, with experts who work alongside your team to take the model to production.

Example

Llama 3 70B runs on four of our GPU nodes. You open it in Caliper on your laptop and read its layers in the Trace pane as you would a local model; the nodes send back the readings, not the activations.

Caliper Platform

A place to exchange widgets and applets, and to source pre-made professional tools.

Example

A lab publishes the spectrogram widget from its own applet. You add its source to your project with caliper add spectrogram; a licensed tool installs into your applets the same way.
